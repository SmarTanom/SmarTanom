# SmarTanom Frontend (Web)

React web client for SmarTanom.

## Fonts: Montserrat

Montserrat (400/600/700) is loaded via Google Fonts in `public/index.html`:

```html
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;600;700&display=swap" rel="stylesheet" />
```

Global CSS is in `src/assets/styles/` and imported from `src/index.js`.

Typography classes:
- Headings use `font-weight: 700` (Bold)
- Body uses `font-weight: 400` (Regular)

## Colors
- Primary Green: `#339432`
- White: `#FFFFFF`
- Neutral text: `#111111` / `#6B7280`
